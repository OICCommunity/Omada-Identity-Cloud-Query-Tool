# Omada-Identity-Cloud-Query-Tool
The Omada Identity Cloud Query Tool is a Windows desktop client for running SQL Troubleshooting queries against Omada Identity Cloud environments through OData. It is intended for diagnostics, configuration analysis, audit lookups, and operational investigations across the available SQL Troubleshooting data connections.

The tool assumes the user understands Omada object models, OIS/Archive/ODW/OPS/RoPE data domains, SQL Server syntax, and the operational impact of querying Omada environments.

## Installation
1. Install .NET 10 Desktop runtime
2. Download tool from releases list
3. Select installer properties -> Unblock File
4. Run the installer
5. Start the tool and review the information available in the help menu in the application
